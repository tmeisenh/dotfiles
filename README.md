# dotfiles

My `$HOME`. Probably of no use to anyone else.  A collection of shell, editor, and terminal settings that is managed by `stow`.

I've been using the zsh shell since the early 2000s and this is why everything is home rolled vs using something like `oh-my-zsh` or `prezto`. My vim settings have ranged from simple setup to a full blown IDE replacement and back to a simple setup.  I have far too much muscle memory to switch anything now.

I started out using GNU/Linux in 1999 (Red Hat, Slackware, Gentoo, Debian and Debian-based systems) and after a few years of that I switched over to FreeBSD. That lasted a couple of years until I moved to OSX/MacOS around 2005. I still prefer FreeBSD but MacOS is more practical for "life" reasons. Nowadays, I'd probably just use Debian if I wasn't so invested in the Apple ecosystem.

In 2006 I decided to store my `$HOME` under `subversion` (Storing dotfiles in vcs was a 'big deal' back then, if you remember that!). This repo has history going back to 2009 when I migrated from a corrupted `subversion` repo to `git` but its tracable origins start in 2003.
